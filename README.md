# S82 Jam

App tập band qua mạng, tiếng Việt, của S82 Studio. Dựa trên [SonoBus](https://github.com/sonosaurus/sonobus) (Sonosaurus LLC, giấy phép GPLv3).

- Tiếng gửi thẳng giữa các máy (P2P), độ trễ thấp, hỗ trợ ASIO trên Windows.
- Giao diện tiếng Việt.

## Tải về

Vào mục **Releases** của kho này:
- Windows: `S82-Jam-Windows.zip`, giải nén rồi chạy `S82 Jam.exe`.
- Mac: `S82-Jam-Mac.dmg`, kéo `S82 Jam` vào Applications. Lần đầu mở: System Settings → Privacy & Security → **Open Anyway**.
